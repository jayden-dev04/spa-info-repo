# spa-info-repo

Fullstack Single Page Application (SPA) with **React 19 + TypeScript + Vite + Tailwind CSS v4 + shadcn/ui** Frontend, **Laravel 12 (PHP 8.4)** Backend API, and **Supabase PostgreSQL** Database.

> 📖 **AI Agent & Architecture Guide**: See [PROJECT_OVERVIEW.md](./PROJECT_OVERVIEW.md) for full project structure, environment configurations, API routes, database schemas, and commands.

## Quick Start (One-Click)

Double-click `run.bat` or run in terminal:
```cmd
run.bat
```

- **Frontend Application**: `http://localhost:5173`
- **Backend API**: `http://127.0.0.1:8000/api/users`
